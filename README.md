# BasketIQ

Smart insights into customer purchase behavior using retail transaction data.
(تحلیل هوشمند رفتار خرید مشتریان بر اساس داده‌های تراکنش خرده‌فروشی)

## Dataset

[Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail) (UCI Machine Learning Repository) — transactional data from a UK-based online retailer.

## Project structure

```
BasketIQ/
├── data/
│   ├── raw/          # original dataset (not tracked in git, download separately)
│   └── processed/    # cleaned data generated by the notebooks
├── notebooks/        # step-by-step analysis notebooks
├── dashboard/        # interactive Streamlit dashboard
├── src/               # reusable code (added as the project grows)
├── reports/figures/    # exported charts and visuals
└── requirements.txt
```

## Setup

```bash
pip install -r requirements.txt
```

Download `Online Retail.xlsx` from the link above and place it in `data/raw/`.

## Notebooks

Run these in order — each one reads the processed output of the previous step:

1. `01_data_loading_cleaning.ipynb` — load the raw dataset, clean it, and save a processed CSV.
2. `02_eda.ipynb` — exploratory analysis of sales trends, products, countries, and customer behavior.
3. `03_rfm_analysis.ipynb` — Recency/Frequency/Monetary scoring and rule-based customer segmentation.
4. `04_clustering.ipynb` — K-Means clustering on RFM features for data-driven customer segments.
5. `05_market_basket_analysis.ipynb` — Apriori association rule mining ("frequently bought together").
6. `06_cohort_analysis.ipynb` — monthly cohort retention analysis.

## Dashboard

Once the notebooks above have been run (so `data/processed/` is populated), launch the interactive dashboard:

```bash
streamlit run dashboard/app.py
```

It presents an overview of revenue KPIs, sales trends, RFM/cluster-based customer segments, market basket association rules, and the cohort retention heatmap — all in one browser-based app.
